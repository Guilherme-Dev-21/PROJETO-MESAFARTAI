PROJETO MESAFARTAI - REGRAS DA ETAPA 2 (FASE 1 - AC-3)
Motor NLU e Trava de Threshold
Valor da etapa: 0,25 ponto na AC-3
========================================================================

OBJETIVO DA ETAPA
Construir a inteligencia de linguagem do MESAFARTAI: o modulo src/nlu.py
com TF-IDF + Random Forest e a Trava de Seguranca (Threshold/Fallback).
O desenvolvimento deve ser feito no VS Code.

O QUE ESTA SENDO PEDIDO

1. Clonar o repositorio
   - No GitHub, botao verde <> Code -> copiar a URL HTTPS.
   - No terminal:
       git clone https://github.com/SEU_USUARIO/PROJETO-MESAFARTAI.git
       cd PROJETO-MESAFARTAI

2. Abrir no VS Code e instalar as bibliotecas
   - Abrir a pasta do projeto no VS Code (code . ou Arquivo -> Abrir Pasta).
   - Criar o arquivo requirements.txt na raiz com:
       streamlit
       scikit-learn
       pandas
       numpy
   - Instalar os pacotes no terminal do VS Code:
       pip install -r requirements.txt

3. Criar o motor NLU (src/nlu.py)
   - Base de treino com frases rotuladas em 4 intencoes:
     cadastrar_doacao, solicitar_alimentos, consultar_status e
     fora_de_escopo.
   - Vetorizacao com TfidfVectorizer (ngram_range=(1, 2)).
   - Classificacao com RandomForestClassifier (n_estimators=80,
     random_state=42).
   - Trava de seguranca: se a confianca maxima for menor que 0.60 ou a
     intencao for fora_de_escopo, o sistema retorna "fallback" com uma
     mensagem pedindo para o usuario reformular o pedido.

4. Executar e testar
   - No terminal do VS Code:
       python src/nlu.py
   - A bateria de testes deve mostrar a intencao, a confianca e o
     retorno de cada frase, com fallback nas frases incertas ou fora de
     escopo.

5. Commit e push para o GitHub
       git add .
       git commit -m "feat(nlu): implementa motor TF-IDF + Random Forest com trava de threshold"
       git push origin main
   - Conferir na pagina do repositorio se o ultimo commit aparece.

ENTREGAS COMPLEMENTARES
   - Incluir as etapas 1 a 5 neste arquivo (docs/regras.txt).
   - Criar o relatorio de execucao em docs/relatório_fase1_etapa2.md.

PROJETO MESAFARTAI - REGRAS DA ETAPA 3 (FASE 1 - AC-3)
Extrator de Entidades (Regex) e Matchmaking Logistico (KNN)
Valor da etapa: 0,5 ponto na AC-3
========================================================================

OBJETIVO DA ETAPA
Implementar o Extrator de Entidades por Regex (src/entities.py) e o
Motor de Matchmaking Logistico por KNN (src/matchmaking.py) utilizando
o VS Code e sincronizando as alteracoes com o GitHub.

PRE-REQUISITO (DESAFIO REGEX)
   - Script no Colab extraindo quantidade/unidade, tipo de alimento e
     validade (dias = perecivel, meses = nao perecivel) sem uso de IA.
   - Print enviado a flavio.santarelli@pro.fecaf.com.br com o assunto
     [DESAFIO REGEX - ADS 4º] (um e-mail por grupo).
   - Codigo salvo em src/desafio_regex.py.

O QUE ESTA SENDO PEDIDO

1. Sincronizar e preparar o repositorio no VS Code
   - Copiar todas as instrucoes desta etapa em docs/regras.txt.
   - Abrir a pasta PROJETO-MESAFARTAI no VS Code (terminal: code .).
   - Baixar as atualizacoes do grupo:
       git pull origin main
   - Se o projeto nao estiver na maquina, voltar a aula 10 e clonar.
   - Garantir as dependencias instaladas:
       pip install -r requirements.txt

2. Criar o extrator de entidades por Regex (src/entities.py)
   - Classe ExtratorEntidades com:
     - padrao_quantidade: numero (inteiro ou decimal com . ou ,)
       seguido de kg, quilos, kilos, caixas ou sacas. Padrao 1.0 kg se
       nao informado.
     - vocabulario_alimentos para identificar o alimento na frase
       (retorna "Alimentos Diversos" se nenhum for encontrado).
     - extrair_validade: "hoje" -> data atual, "amanha" -> +1 dia,
       caso contrario -> +3 dias (formato YYYY-MM-DD).
     - processar_texto: retorna alimento, quantidade_kg e data_validade.

3. Criar o motor de matchmaking KNN (src/matchmaking.py)
   - Classe MotorMatchmaking que garante a tabela usuarios e insere
     ONGs de teste caso nao existam.
   - buscar_ongs: le todas as ONGs (id, nome, latitude, longitude) do
     SQLite.
   - encontrar_ong_mais_proxima: NearestNeighbors (n_neighbors=1,
     metric='euclidean') sobre as coordenadas das ONGs; retorna a ONG
     mais proxima do doador e a distancia aproximada em km (x 111).

4. Executar e validar no terminal do VS Code
       python src/entities.py
       python src/matchmaking.py
   - As saidas devem ser exibidas sem erros.

5. Commit e push final para o GitHub
       git add .
       git commit -m "feat(logistics): implementa extracao por regex e matchmaking knn"
       git push origin main

CHECKLIST
