criacao do banco de dados SQLite e carga inicial de dados de teste.

O QUE ESTA SENDO PEDIDO

1. Organizacao do grupo e repositorio

   - Criar um repositorio PUBLICO no GitHub com o nome exato PROJETO-MESAFARTAI.
   - Adicionar todos os integrantes e o professor como colaboradores.

2. README.md e pasta /docs
   - README.md na raiz com o titulo oficial do projeto, descricao resumida
     da solucao, alinhamento com a ODS 2 da ONU e nome completo e RA de
     cada integrante.
   - docs/regras.txt descrevendo o que esta sendo pedido na etapa 1
     (este arquivo).
   - docs/escopo_projeto.md descrevendo o problema de negocio, o
     publico-alvo (Doadores x ONGs), o escopo das intencoes tratadas e os
     dados coletados no chat.
   - As imagens arquitetura_mesafartai.png e diag_fluxo_mesafartai.png
     devem constar na pasta /docs.

3. Identidade visual
   - Criar um prompt e gerar o logotipo do sistema com um gerador de
     imagem por IA.
   - O logo deve unir os conceitos de alimento/acolhimento e
     tecnologia/IA assistiva.
   - Salvar a imagem em assets/logo_mesafartai.png.
   - Registrar o prompt exato utilizado em docs/escopo_projeto.md.

4. Banco de dados
   - Criar o script src/database.py, que inicializa o banco SQLite3
     mesafartai.db com as tabelas usuarios, doacoes e matches e insere a
     carga inicial de teste (2 ONGs e 2 doadores).
   - O script deve executar sem erros e gerar o arquivo mesafartai.db.

5. Envio
   - Enviar e-mail ao professor ate o final do horario da aula.
   - Assunto: [MESAFARTAI] - Nome do Grupo - Turma Terca
   - Corpo: lista dos integrantes (Nome + RGM + Curso) e link direto do

PROJETO MESAFARTAI - REGRAS DA ETAPA 2 (FASE 1 - AC-3)
Motor NLU e Trava de Threshold
Valor da etapa: 0,25 ponto na AC-3
========================================================================

OBJETIVO DA ETAPA
Construir a inteligencia de linguagem do MESAFARTAI: o modulo src/nlu.py
com TF-IDF + Random Forest e a Trava de Seguranca (Threshold/Fallback).
O desenvolvimento deve ser feito no VS Code.

O QUE ESTA SENDO PEDIDO

1. Clonar o repositorio
   - No GitHub, botao verde <> Code -> copiar a URL HTTPS.
   - No terminal:
       git clone https://github.com/SEU_USUARIO/PROJETO-MESAFARTAI.git
       cd PROJETO-MESAFARTAI

2. Abrir no VS Code e instalar as bibliotecas
   - Abrir a pasta do projeto no VS Code (code . ou Arquivo -> Abrir Pasta).
   - Criar o arquivo requirements.txt na raiz com:
       streamlit
       scikit-learn
       pandas
       numpy
   - Instalar os pacotes no terminal do VS Code:
       pip install -r requirements.txt

3. Criar o motor NLU (src/nlu.py)
   - Base de treino com frases rotuladas em 4 intencoes:
     cadastrar_doacao, solicitar_alimentos, consultar_status e
     fora_de_escopo.
   - Vetorizacao com TfidfVectorizer (ngram_range=(1, 2)).
   - Classificacao com RandomForestClassifier (n_estimators=80,
     random_state=42).
   - Trava de seguranca: se a confianca maxima for menor que 0.60 ou a
     intencao for fora_de_escopo, o sistema retorna "fallback" com uma
     mensagem pedindo para o usuario reformular o pedido.

4. Executar e testar
   - No terminal do VS Code:
       python src/nlu.py
   - A bateria de testes deve mostrar a intencao, a confianca e o
     retorno de cada frase, com fallback nas frases incertas ou fora de
     escopo.

5. Commit e push para o GitHub
       git add .
       git commit -m "feat(nlu): implementa motor TF-IDF + Random Forest com trava de threshold"
       git push origin main
   - Conferir na pagina do repositorio se o ultimo commit aparece.
